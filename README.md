#  Downloaded-it

Una solución web minimalista para la gestión y descarga de contenido multimedia. Desarrollada como proyecto de automatización para optimizar el acceso a recursos multimedia desde una interfaz limpia y eficiente.

##  Stack Tecnológico

* **Backend:** Python 3.12 + Flask
* **Engine:** yt-dlp
* **Frontend:** HTML5 / CSS3 (Diseño responsivo con Flexbox)
* **Deployment:** Render (PaaS)

##  Características

* **Gestión de Calidad:** Selector dinámico para optimizar el peso de los archivos (Alta/Baja resolución).
* **Arquitectura Adaptativa:** Configuración híbrida preparada para ejecución en entornos locales y servidores en la nube.
* **Interfaz Mobile-First:** Experiencia de usuario fluida y centrada, optimizada para dispositivos móviles.

##  Instalación y Uso

1. Clonar el repositorio:
```bash
git clone [https://github.com/cableOTA-png/WebDownload.git](https://github.com/cableOTA-png/WebDownload.git)
```
2. Instalar dependecias:
```bash
pip install -r requirements.txt
```
3. Ejecutar el servidor:
```bash
python app.py
```
